## How to upload your code

You only need a **GitHub account**. No Git or command line needed — everything is done in the browser.

Every student has their own folder:

```
students/
└── YOUR-GITHUB-USERNAME/
    ├── task-1/
    ├── task-2/
    └── task-3/
```

Replace `YOUR-GITHUB-USERNAME` with your exact GitHub username (the name shown in the top-right menu after you sign in).

### Option A — paste your code (one file)

1. Sign in to GitHub and open this repository.
2. Click the **`students`** folder.
3. Click **Add file → Create new file**.
4. In the name box, type the full path, for example:
   `YOUR-GITHUB-USERNAME/task-2/linked_list.cpp`
   (typing `/` creates a folder automatically.)
5. Paste your code into the big box.
6. Click **Commit changes… → Propose changes**.
7. Click **Create pull request**, then **Create pull request** again.

### Option B — upload several files

1. On your computer, make a folder named exactly like your GitHub username.
   Inside it, make a folder named `task-2` (or `task-1`, `task-3`) and put your code files in it.
2. Sign in to GitHub, open this repository and click the **`students`** folder.
3. Click **Add file → Upload files**.
4. **Drag your username folder** onto the page (dragging keeps the folders; this works in Chrome, Edge and Firefox on a computer).
5. Click **Propose changes**, then **Create pull request** twice.

### After you upload

- A pull request is your submission. Your teacher reviews it and adds it to the repository.
- An automatic check runs on your pull request. A ✅ means your files are in the right place.
  A ❌ means something is wrong — open **Details** to see what to fix.
- To fix a mistake, upload again the same way, or click **Files changed** in your pull request and edit the file.

### Rules

- Only add files inside **your own** folder: `students/YOUR-GITHUB-USERNAME/task-N/`.
- Upload **source code only** (`.cpp`, `.c`, `.h`, `.py`, `.java`, `.js`, `.cs`, …). No `.exe`, `.zip`, or build folders.
- Each file must be smaller than 1 MB.
- Don't edit or delete other students' files.

## خطوات رفع الكود (بالعربي)

1. سجّل دخولك على GitHub وافتح هذا الـ repository.
2. ادخل على فولدر **`students`**.
3. اضغط **Add file ← Create new file**.
4. اكتب المسار كاملًا، مثال: `اسم-المستخدم/task-2/linked_list.cpp`
   (علامة `/` بتعمل فولدر تلقائيًا، واكتب اسم المستخدم بتاعك على GitHub بالظبط).
5. الصق الكود.
6. اضغط **Commit changes… ← Propose changes** ثم **Create pull request** مرتين.

لو عندك أكتر من ملف: اعمل على جهازك فولدر باسم المستخدم بتاعك، جواه فولدر `task-2` وفيه الملفات،
وبعدين من داخل فولدر `students` اضغط **Add file ← Upload files** واسحب الفولدر كله وافلته في الصفحة.

ارفع ملفات الكود فقط، وجوه الفولدر بتاعك بس.
